AuditFlow Lite — Architecture (High-Level) [Revised v0.1-ready]

Goal:
- One-shot, read-only evidence collection (no mutation of user data)
- Append-only evidence store (SQLite) ENFORCED (no UPDATE/DELETE on evidence/chain/artifacts)
- Tamper-evident chain with run sealing (final_chain_hash + evidence_count)
- Human-readable reports + optional read-only web UI

──────────────────────────────────────────────────────────────────────────────
[User]
  ├─ runs CLI commands (init/plan/run/diff/verify/export)
  └─ reads reports (md/html) and makes decisions

  EvidenceRecords            auditflow.db                 artifacts/<run_id>/
  (canonical JSON +          (append-only ENFORCED)       report.md / diff.md
   optional attachment files)                             (and/or html)

Notes on integrity:
- attachment files are hashed (attachment_sha256) and INCLUDED in payload_hash
- artifact files are hashed (artifacts.sha256) and recorded in DB
- (recommended) artifact manifest is also recorded as Evidence(kind=artifact_manifest)
  so report/diff hashes are covered by the same chain
